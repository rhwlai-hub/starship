# Starship

A starship command game for iPhone, played in the browser. Command the survey ship Explorer through five galaxies held by the Kethari Dominion: explore, manage power, send landing parties, fight, and upgrade the ship. Every voyage starts fresh.

A personal hobby project.

## Play

Open the game's GitHub Pages address in Safari on an iPhone, then tap Share, then **Add to Home Screen**. After the first visit it works offline. Tap **How to play** at the bottom of the game for the rules.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole game: layout, rules and code in one page |
| `art/` | Painted encounter pictures |
| `sw.js` | Offline support: keeps the game and pictures on the phone |
| `manifest.webmanifest`, `icon-*.png` | Let the game install to the home screen like an app |

Saved games, records, achievements and tuning are stored on the device only.

## Assets

| Asset | Source | Use |
| --- | --- | --- |
| Paintings in `art/` | Generated with ChatGPT from the author's own prompts | Made for this game |
| Drawn scenes, sound and music | Generated by the game's own code | Original |
| Fonts (Chakra Petch, IBM Plex Sans) | Google Fonts, SIL Open Font License | Loaded from Google Fonts; the phone's own fonts are used if they are unavailable |

All names, factions and settings are original.
